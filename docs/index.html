Instalar por plataforma

Escolha seu sistema. O comando baixa o toolbox completo e abre o Jarvis — ele descompacta o OpenCode e vem conversando com você.

🪟 Windows

Recomendado: package manager oficial do Windows.

winget install davisoliveira1520-cmd.Jarvis

⚠️ O pacote winget depende da aprovação do PR #436513. Até lá, use o método manual:

cd $env:USERPROFILE git clone --depth 1 https://github.com/davisoliveira1520-cmd/fullstack-agent-opencode.git jarvis .\jarvis\jarvis.bat

Depois do download, é só duplo-clique em jarvis.bat. Ele extrai o OpenCode de bin\ e abre o assistente falando com você.

Nota: no Windows, o binário do OpenCode já vem embutido em bin\opencode-windows-x64.zip — nada é baixado de fora.
🍎 macOS

Instale via Homebrew (tap oficial) ou manualmente:

brew tap davisoliveira1520-cmd/jarvis brew install jarvis jarvis.sh

Ou manual:

git clone --depth 1 https://github.com/davisoliveira1520-cmd/fullstack-agent-opencode.git jarvis cd jarvis chmod +x jarvis.sh ./jarvis.sh
O primeiro jarvis.sh baixa o binário certo do OpenCode para bin/ automaticamente (uma vez só).
🐧 Linux (Debian/Ubuntu etc.)
sudo apt install curl unzip -y git clone --depth 1 https://github.com/davisoliveira1520-cmd/fullstack-agent-opencode.git jarvis cd jarvis ./jarvis.sh
Garanta python3 instalado (já vem na maioria das distribuições). O jarvis.sh cuida do resto.
🤖 Android (Termux)

Usa o binário Linux arm64 — funciona normalmente:

pkg update && pkg install git curl unzip -y git clone --depth 1 https://github.com/davisoliveira1520-cmd/fullstack-agent-opencode.git jarvis cd jarvis ./jarvis.sh
📱 iOS

Sem suporte nativo — o OpenCode não roda de verdade no terminal do iPhone/iPad.

# experimental: app iSH (emula Linux x86_64) — instável e lento
Recomendado: use a versão web do OpenCode (opencode web) em qualquer navegador.

Perguntas frequentes

Rápido, antes de você começar.

O que acontece depois do comando de instalação?
O Jarvis abre direto num assistente já conversando com você. Ele pergunta seu nome e a personalidade do seu agente (ou entrega o Jarvis pronto), quais peças você quer e onde suas notas vivem. Ele mesmo instala, configura e liga tudo.
Preciso de hardware especial?
A voz precisa de um microfone e cerca de 1 GB de modelos locais no primeiro uso. As mãos precisam de webcam e Chrome. A mente e a face só precisam de Python 3. O resto é conversa.
Como atualizo?
No macOS: ./fullstack-agent/update.sh. No Windows, peça: "atualize tudo e me diga o que mudou". Seus arquivos ficam fora dos repos — atualizar nunca toca em quem o seu agente é ou no que ele lembra.
Ei, deu algum problema. E agora?
Abra o chat e descreva o problema — o Jarvis foi instruído a se consertar sozinho. Cada repo aqui tem um guia de troubleshooting escrito para o agente ler.
O winget ainda está em aprovação?
Sim. O PR #436513 está em validação na Microsoft. Enquanto isso, use o comando manual do Windows — funciona já.
