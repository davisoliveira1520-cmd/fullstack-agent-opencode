# Jarvis

Assistente pessoal inteligente, construído com o OpenCode (no lugar do Claude Code).

## Configuração

- `opencode.json` — configuração principal do OpenCode.
- `.opencode/agent/fullstack.md` — agente fullstack que desenvolve o projeto.
- `.opencode/skills/jarvis/SKILL.md` — skill central do Jarvis.

## Como usar

Rode o OpenCode na raiz do projeto. O agente `fullstack` é o padrão.
